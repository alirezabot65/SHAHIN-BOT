# 𝑺𝑯𝑨𝑯𝑰𝑵 𝑩𝑶𝑻

نسخه اولیه سایت ربات‌ساز روبیکا.

## اجرا

```bash
python -m pip install -r requirements.txt
python app.py
```

بعد مرورگر را روی `http://127.0.0.1:5000` باز کنید.

## ورود
در نسخه فعلی ورود با **توکن ربات** انجام می‌شود و پس از اعتبارسنجی، اطلاعات پایه ربات در داشبورد نمایش داده می‌شود.

## مرحله بعد
- پیام استارت و خوش‌آمدگویی
- مدیریت کاربران
- پیام همگانی PV و گروه
- پاسخ سریع
- آپلود فایل
- دکمه‌های کیبورد و شیشه‌ای
- چیدمان دکمه‌ها
- تگ
- VIP و عضویت اجباری
- پنل ادمین
- آمار و گزارش فعالیت
- تست واقعی دریافت/ارسال پیام در گروه
- امنیت و نگهداری امن توکن‌ها
